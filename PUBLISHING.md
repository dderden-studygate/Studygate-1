# Publish Study Gate

This app is ready for static hosting.

## What to upload

Upload the contents of this folder, keeping these files together:

- `index.html`
- `outbox.html`
- `manifest.webmanifest`
- `sw.js`
- `icons/`

You can include `README.md` if you want, but it is not required for the app to run.

## What users get

- A phone-friendly web app
- Home screen install support when opened over HTTPS
- Local progress saved on each device
- Local outbox support for quiz results and parent confirmations

## What is not live yet

- Shared accounts between phones
- Real cloud sync
- Real email/text delivery

Those would need a backend later.

## Simple publish flow

1. Upload this folder to any HTTPS static host.
2. Open the public URL on a phone.
3. Tap the browser install option or Add to Home Screen.
