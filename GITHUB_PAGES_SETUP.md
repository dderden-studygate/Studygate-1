# GitHub Pages Setup

This package is ready to use with GitHub Pages.

## Recommended setup

1. Create a new public GitHub repository.
2. Upload the contents of this folder to the root of that repository.
3. On GitHub, open the repository.
4. Go to **Settings**.
5. In the left sidebar, go to **Pages**.
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Choose the `main` branch and the `/(root)` folder.
8. Click **Save**.

GitHub Pages will publish the site and give you a URL like:

`https://yourusername.github.io/your-repository-name/`

## What to send people

Send them the final public GitHub Pages URL, not the zip file.

## Important note

This app stores progress and outbox data locally on each phone. It does not sync between devices yet.
